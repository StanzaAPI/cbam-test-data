# CBAM Test Data

Rows for CBAM reporting tests: declaration id, CN code, quantity, unit, embedded emissions, and country of origin. Synthetic values.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

## Files

- `cbam-small.json`
- `cbam-small.csv`
- `cbam-medium.json`
- `cbam-medium.csv`
- `cbam-large.json`
- `cbam-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
